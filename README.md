## COLE IM APP Window Client
# version: 0.1.0 - 2026-10-16


## 可乐IM APP 客户端 (Window 版)


# SING
- 这是一个使用RUST Gpui-kit(0.7.3 2026-10) 开发的软件

# 特点
- 带有统一的SDK, 实现了网络endpoint无感刷新切换, Sqlite本地户存储, 多账户隔离, 数据加解密等功能.
ABI: 提供给RUST的同进程调用, Kotlin / Java / Swift的FFI调用, 可以单独打包成静态库, 嵌入其他平台客户端当SDK使用.
